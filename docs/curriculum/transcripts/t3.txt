[Content Placeholder 2] elif – is a keyword used in Python in replacement of else if  to place another condition in the program. This is called chained conditional.
Any number of elif part can be there.
Syntax
		if  condition1:
		           <statements 1>
		elif condition2:
			<statements 2>
		elif condition3:
			 <statements 3>
			   .
			   .
		else:
		      	<statements n>
